# dsh-meow-smooth 喵丝滑——手机端远程使用dsh，躺着coding，刷b站coding

## 简介

dsh（DeepSeek Harness）前端体验增强插件，**零 dsh 本体改动**，纯客户端自包含。
装上之后，dsh 在手机上像原生 App 一样好摸，在电脑上也有更舒服的小细节。

tailscale实现手机端远程连接dsh（插件包含tailscale配置踩坑指导，AI看完应该可以帮你快速实现手机连接dsh，你就不用自己从零开始踩坑了。）

手机端ui交互优化，让手机端dsh真正可用。你可以躺着coding了。

电脑、手机都支持的通知系统。AI跑任务，你切出去刷b站了，AI跑完任务或者中途提问，会发通知给你。

还有一些ui交互方面的细节优化。

作者自己在用，亲测好用，非常提高幸福感。

## 核心特性

### 手机上更像原生 App

| 能力 | 说明 |
| --- | --- |
| **边缘手势抽屉** | 屏幕左缘往右轻划唤出侧边栏，再划一下展开完整侧边栏，长划一步到位；点外面或往左一划收起。三档停留全是原生状态。 |
| **返回手势当抽屉用** | 手机浏览器里左缘右划（或按返回键）不再退出页面，而是打开侧边栏；AI 跑着任务也绝不会被一滑带走。 |
| **细竖条折成小方块** | 收起后的细竖条折叠成左上角一个带 DeepSeek 图标的方块，会话标题自动让位；点一下直接展开完整侧边栏，选完自动折回。装了会往侧边栏加按钮的插件时，小方块自动让位回原生竖条。 |
| **侧边栏更聪明** | 窄屏下切换会话后自动收起，把屏幕还给对话；展开时点一下右侧空白就收起。 |
| **按钮行永不换行** | 窗口再窄，权限 / 模型 / 上下文 / 发送都稳在一行 —— 模型名自动缩短省略，权限按钮自动收成图标，不再整排掉到第二行。 |
| **模式选择只留图标** | agent preset 在手机上只显示一个小图标，点一下展开完整名字，点别处自动收回。 |
| **宽手机右侧面板分屏**（dsh 0.1.6+） | 折叠屏内屏、小平板（约 560–768px）上文件面板不再整屏盖住对话，左右各半；普通手机（≤480px）保持全屏。 |
| **设置页适配手机** | 手机上全屏显示、左侧边栏收成图标列；电脑保持官方原样。 |

### 打字与输入

| 能力 | 说明 |
| --- | --- |
| **输入框失焦自动折叠** | 长草稿不再占半屏。电脑保留 2 行、手机收成 1 行；点一下又展开，草稿内容与滚动位置原样保留。 |
| **手机上回车 = 换行** | 不怕误触把半截话发出去；Shift/Ctrl/Enter 与输入法选词不受影响，桌面键盘依旧回车发送。 |
| **AI 运行时多一个插话按钮** | AI 回话时发送键旁多出一个小箭头，等价于按一次回车；手机虚拟键盘没有 Ctrl/Cmd，运行中插话全靠它。 |
| **打字时顶部栏自动让位** | 唤起输入法时标签自动隐藏，只留当前会话名；键盘收起一切恢复。 |
| **手机拍 / 选图**（dsh ≤0.1.2） | 输入栏右侧 📷 直接调起拍照 / 相册，走与桌面拖图**同一条官方附件管线**；0.1.3-alpha.2 起官方自带选图入口，本插件探测到就不重复显示。 |

### 通知（电脑、手机都支持）

| 能力 | 说明 |
| --- | --- |
| **页面内提醒卡片** | AI 中途要权限、有问题等你回答、或回合因错误中断，屏幕上方弹卡片，点一下跳过去处理。 |
| **系统通知** | AI 跑完长任务 / 要权限 / 提问，哪怕你切出去刷 B 站也会弹通知，点通知直接回到对应会话。 |
| **多会话同时跑也不错过** | 一次开好几个会话，你在跟其中一个聊，别的会话有动静同样提醒你。 |
| **运行失败也提醒** | 回合因错误中断时同样提醒；自动重试中的瞬时错误不打扰，只有最终失败才提醒，每条恰好一条。 |
| **手机也能收到** | 桌面与安卓直接弹；iPhone 通过 Web Push 或 Bark 等通道。 |
| **不打扰** | 电脑端页面正聚焦时不弹系统通知，切到别的窗口才弹。 |

### 手机上访问更快（可选）

| 能力 | 说明 |
| --- | --- |
| **内置压缩代理** | 把大会话的历史记录响应压缩 **70–90%**，蜂窝网络也流畅；流式输出与实时连接不受影响。**默认关闭**，开启步骤见 [docs/访问加速.md](docs/访问加速.md)。 |
| **自动分辨宿主版本** | 老版 dsh 没有响应压缩就压缩历史记录；新版自己会压缩，代理自动切成纯透传，不多绕一层。判断靠实测能力、不认版本号。 |

### 其它细节

- **顶部栏与回答信息行可横滑**：Session 名永不截断，统计不再被屏幕边缘切掉。
- **禁止意外缩放**：双击、双指捏合都不再让页面意外缩放。
- **表格触摸滚动修复**：从表格任意位置起手都能正常滑动页面，宽表还能左右滑。
- **禁用橡皮筋回弹**：页面下拉不再回弹，更像原生 App 的手感。
- **小图标化**：下载记录、后台任务、子代理等按钮在手机上缩成紧凑小图标，依旧一点就开。
- 电脑上也保留同样的折叠与让位行为，只是行数与手机不同。

## 快速开始

## 安装

**从 GitHub 安装**：源码在 `src/`，`lib/` 不入仓库，安装时 npm 会触发 `prepare` 脚本现场构建，装完即用。

```powershell
dsh plugin --profile web add github:Phant0Meow/dsh-meow-smooth
```

**从 npm 安装**：包内已含构建产物 `lib/index.js` 与 `lib/client.js`，安装时不再构建。

```powershell
dsh plugin --profile web add meow-smooth
```

两种方式装完都会自动挂载，重启 DSH web 后启用，无需手工编辑任何组合文件。

> npm 源 `dsh plugin --profile web add meow-smooth` 自 `0.6.1` 起恢复可用；`0.6.0` 及更早版本的 `package.json` 带 BOM 会解析失败，请避开。GitHub 源始终最新，推荐优先使用。

## 卸载

```powershell
dsh plugin --profile web remove meow-smooth
```

彻底移除，重启 DSH web 后不再加载。

## 兼容性

支持 **dsh 0.1.5**（含最新的 `0.1.5-rc.1`），同时向下兼容旧版本——升级 dsh 不需要改本插件，也不需要改配置，手机端链接（tailscale serve 指向）照旧。

其中的手机访问加速代理会自动分辨宿主版本：老版 dsh 没有响应压缩，代理就压缩历史记录；新版 dsh 自己已经会压缩，代理自动切成纯透传，不再多绕一层。这个判断靠实测能力、不认版本号，所以夹在中间的版本也各有正确行为。
